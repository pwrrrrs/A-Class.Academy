# A-Class Academy — เว็บไซต์และระบบเรียนออนไลน์

เว็บไซต์สถาบันกวดวิชา A-Class Academy (ลำพูน) พร้อมระบบสมาชิก คอร์สออนไลน์ แบบทดสอบ ความคืบหน้า รับชำระผ่าน PromptPay + แนบสลิป และหลังบ้านสำหรับครู

**ค่าใช้จ่าย: 0 บาท** — ใช้ Vercel (ฝากเว็บ) + Supabase (ฐานข้อมูล/ล็อกอิน/เก็บสลิป) แบบฟรีทั้งหมด

---

## ติดตั้งครั้งแรก (ทำครั้งเดียว)

### 1. สร้างฐานข้อมูล
Supabase → **SQL Editor** → New query → วางเนื้อหาไฟล์ [`supabase/schema.sql`](supabase/schema.sql) ทั้งหมด → **Run**
(รันซ้ำได้ ไม่ลบข้อมูลเดิม — ใช้ตอนอัปเดตระบบในอนาคตด้วย)

### 2. เอาเว็บขึ้น Vercel
1. vercel.com → **Add New… → Project**
2. เลือก repository **A-Class.Academy** → **Import**
3. Framework Preset: **Other** (ไม่ต้องแก้อย่างอื่น) → **Deploy**
4. ได้ลิงก์เว็บ เช่น `https://a-class-academy.vercel.app`

ทุกครั้งที่มีการแก้โค้ดใน GitHub, Vercel จะอัปเดตเว็บให้เองอัตโนมัติ

### 3. บอก Supabase ว่าเว็บอยู่ที่ไหน (สำคัญ — ไม่ทำแล้วลิงก์ในอีเมลจะพัง)
Supabase → **Authentication → URL Configuration**
- **Site URL**: ใส่ลิงก์เว็บจาก Vercel เช่น `https://a-class-academy.vercel.app`
- **Redirect URLs**: กด Add URL → ใส่ `https://a-class-academy.vercel.app/**`

### 4. (แนะนำ) ปิดการยืนยันอีเมล
Supabase แบบฟรีส่งอีเมลได้แค่ไม่กี่ฉบับต่อชั่วโมง ถ้านักเรียนสมัครพร้อมกันหลายคนอาจไม่ได้รับอีเมลยืนยัน
Supabase → **Authentication → Sign In / Providers → Email** → ปิด **Confirm email** → Save
(ข้อเสีย: ใครกรอกอีเมลผิดก็ยังสมัครได้ — แต่ครูตรวจสลิปเองอยู่แล้ว จึงไม่กระทบ)

### 5. ตั้งตัวเองเป็นแอดมิน
1. เข้าเว็บ → **เข้าสู่ระบบ → สมัครสมาชิก** ด้วยอีเมลของครู
2. Supabase → SQL Editor → รัน (เปลี่ยนอีเมลเป็นของครู):
   ```sql
   update public.profiles set role = 'admin'
   where id = (select id from auth.users where email = 'อีเมลของครู@gmail.com');
   ```
3. รีเฟรชเว็บ จะเห็นเมนู **หลังบ้าน**

### 6. ตั้งค่าในหลังบ้าน
**หลังบ้าน → ตั้งค่าเว็บ**: เลขพร้อมเพย์, LINE ID, เบอร์โทร, ที่อยู่, เพจ Facebook, รูปครู
**หลังบ้าน → คอร์สและบทเรียน**: ใส่ราคา รายละเอียด รอบเรียน และเพิ่มบทเรียน

## ใช้งานประจำวัน

| อยากทำอะไร | ไปที่ |
|---|---|
| ตรวจสลิป / เปิดคอร์สให้นักเรียน | หลังบ้าน → ตรวจสลิป → **อนุมัติ** |
| นักเรียนจ่ายเงินสด / โอนนอกระบบ | หลังบ้าน → นักเรียน → **+ เพิ่มคอร์ส** |
| เพิ่มคลิปบทเรียน | อัปโหลด YouTube แบบ **ไม่เป็นสาธารณะ (Unlisted)** → คัดลอกลิงก์ → หลังบ้าน → คอร์ส → บทเรียน → วางลิงก์ |
| ทำแบบทดสอบท้ายบท | หลังบ้าน → คอร์ส → จำนวนบท → คอลัมน์ "แบบทดสอบ" |
| ให้บทไหนดูฟรี (ดึงคนสมัคร) | ติ๊ก "ให้คนทั่วไปดูฟรี" ในบทนั้น |
| ส่วนลดรุ่นก่อตั้ง / ชวนเพื่อน | หลังบ้าน → คูปอง |
| ซ่อนคอร์สชั่วคราว | แก้คอร์ส → เอาติ๊ก "แสดงบนเว็บไซต์" ออก |

**แบ่งจ่าย 3 งวด**: ระบบคิด 40% / 30% / 30% ให้อัตโนมัติ นักเรียนเห็นงวดที่ค้างในหน้า "ห้องเรียนของฉัน" และกดจ่ายงวดถัดไปได้เอง

## เปลี่ยนโทนสี
แก้ไฟล์ [`assets/js/config.js`](assets/js/config.js) บรรทัด `TONE:` เป็น `'indigo'` (ครามทอง), `'emerald'` (เขียวมรกต) หรือ `'plum'` (ม่วงพลัม)

## ความปลอดภัย
- ข้อมูลทุกตารางถูกป้องกันด้วย Row Level Security: นักเรียนเห็นเฉพาะข้อมูลของตัวเอง
- ราคาและส่วนลดคำนวณที่ฐานข้อมูล นักเรียนแก้ยอดเงินเองไม่ได้
- เฉลยแบบทดสอบไม่ถูกส่งไปที่เครื่องนักเรียนจนกว่าจะกดส่งคำตอบ
- สลิปเก็บแบบส่วนตัว เห็นได้เฉพาะเจ้าของสลิปและครู
- คลิปฝังบนหน้าที่ต้องล็อกอิน + ลายน้ำชื่อนักเรียน (YouTube Unlisted ป้องกันการแชร์ได้ระดับหนึ่ง ไม่ใช่ 100%)
- **ห้ามใส่ `service_role` / secret key ของ Supabase ในโค้ดเด็ดขาด**

## Supabase ไม่หลับ
แพ็กเกจฟรีของ Supabase จะหยุดทำงานถ้าไม่มีคนใช้ 7 วัน ไฟล์ `.github/workflows/keep-supabase-awake.yml` ปลุกฐานข้อมูลทุก 3 วันให้อัตโนมัติ

## โครงสร้างไฟล์
```
index.html, course.html, login.html, my.html, learn.html, checkout.html, admin.html
assets/css/style.css        หน้าตาและโทนสี
assets/js/config.js         ค่าเชื่อม Supabase + โทนสี
assets/js/core.js           ส่วนกลาง (ล็อกอิน, หัว/ท้ายเว็บ)
assets/js/i18n.js           ข้อความไทย/อังกฤษ
assets/js/promptpay.js      สร้าง QR พร้อมเพย์
assets/js/pages/*.js        โค้ดของแต่ละหน้า
supabase/schema.sql         ฐานข้อมูลและสิทธิ์การเข้าถึง
```
